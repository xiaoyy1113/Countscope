SCOPE 区域特征检索工具｜本机安装版 1.1

一、先双击“00_使用说明.html”，在浏览器阅读完整中文说明。

二、首次安装
1. 完整解压，不要在压缩包内运行。
2. 安装 Python 3.11 或 3.12（64位），勾选 Add python.exe to PATH。
3. 有 NVIDIA 显卡：运行 01_安装环境_NVIDIA.cmd。
   没有 NVIDIA 显卡或不确定：运行 01_安装环境_CPU.cmd。
4. 运行 04_环境检查.cmd，检查模型权重和整图推理。
5. 双击 02_启动工具.cmd，即可在浏览器操作。

三、日常使用
网页地址：http://127.0.0.1:8775/
本地址需要先启动本机程序，不是公网共享链接。
在网页中输入本机 PNG 文件夹路径，从同一或不同图片中人工选择 1–5 个阳性参考点。
参考框固定为 14×14；模型读取整张图片，并取每个位置与参考库的最高相似度。
每张图片可返回多个候选，相似度不等于阳性概率；需要在完整 Patch 审核中删除假阳性并补充漏检点。
用完请运行 03_停止工具.cmd。

四、原始 SVS/TIF
运行 05_批量切片转PNG.cmd，按提示输入源目录和输出目录。
图块尺寸可用 256 或 512，最低前景占比默认 1/3，也可设为 0 保留全部。
组织过滤是颜色/亮度估计，新批次应检查有无浅染组织被省略。

五、已附带的内容
DINOv2 ViT-S/14 权重、所需模型运行代码、中文说明、安装/启动/停止入口、环境检查及切片导出工具。
不包含患者图片、预先计算的特征或完整 Python 依赖离线安装包。首次安装需要联网。
CPU 和 NVIDIA 环境在本文件夹的 .venv 中安装，不依赖原电脑路径。

新增红色信号筛选，操作见“红色筛选说明.txt”。
